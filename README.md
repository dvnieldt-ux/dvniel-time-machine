# DVNIEL Time Machine

Una radio/arqueología musical para explorar grabaciones históricas reales por época y territorio.

## MVP v0.1

- Épocas 1900–1959.
- Búsqueda por territorio con alias históricos (por ejemplo Turkey / Ottoman / Constantinople / Istanbul / Anatolia).
- Grabaciones y metadatos obtenidos de Internet Archive.
- Reproductor integrado, anterior/siguiente/aleatorio.
- Fuente original y aviso de derechos.
- Favoritos guardados localmente.
- Estimación experimental de BPM en el navegador y caché local.

> El BPM de grabaciones antiguas es una estimación: puede existir deriva de tempo y ambigüedad half-time/double-time. Escuchar una grabación no implica permiso para samplearla o reutilizarla.

## Publicación

El proyecto es estático (`index.html`, `styles.css`, `app.js`) y está preparado para GitHub Pages.
